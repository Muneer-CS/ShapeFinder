# ShapeFinder v0.2.0

ShapeFinder v0.2.0 expands market coverage while preserving the existing similarity scorer and making partial coverage explicit. This document is prepared for the `0.2.0-rc.1` development release candidate; production remains on v0.1.0 until approval and promotion.

## Highlights

- Automatic discovery of active U.S. common-stock universes from provider metadata.
- Bounded, cache-aware market-data hydration during named-universe searches.
- Persistent SQLite coverage growth and reuse across searches and restarts.
- Range-aware failure classification and cooldowns without exposing provider details.
- Candidate selection that prioritizes useful partial histories, then spreads work deterministically across the universe.
- Minimum-similarity filtering with `Any similarity` retained as the default.
- Evidence-backed guidance: 75%+ is exploratory, 80%+ is a useful starting point, 85%+ is strong, and 90%+ is exceptional/rare.
- A concise, non-blocking warning for reference windows of 15 bars or fewer.

## Operational notes

- Hydration remains deliberately capped per search and uses the existing backend-only Twelve Data credential.
- Successful histories, universe metadata, coverage records, and failure cooldown metadata use the configured persistent SQLite volume.
- Search responses disclose known, scan-ready, hydrated, scanned, and skipped counts; named-universe results do not claim full-market coverage.
- The similarity formula, weights, normalization, interpolation, ranking, and overlap suppression are unchanged from v0.1.0.

## Known limitations

- Broad coverage grows gradually under provider availability and free-tier quota limits.
- Named-universe searches can return partial coverage; the interface always reports that coverage.
- Very short reference windows can inflate similarity scores even when the shapes are less distinctive.
- Scores at or above 90% were absent from the 62,916-window cached evaluation and should be expected to be rare.
- Failed-symbol progression is process-local, although successful cache data and failure cooldown records persist across restarts.
- Intraday windows can span overnight or exchange-session boundaries.
- SQLite and search admission are designed for a single backend process, not distributed multi-worker writes.
- ShapeFinder compares historical chart shapes. It does not predict prices, provide investment advice, or guarantee future performance.
